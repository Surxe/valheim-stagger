# valheim-stagger

Which Valheim weapon, at which upgrade level, can stagger which creature, at which star level?

Damage alone doesn't answer that. A creature's stagger meter **decays**, so attacks that are
too weak or too slow never fill it, even if they eventually deal 100% of its health. This
repo models the mechanic from the decompiled game code, feeds it wiki-sourced weapon and
creature data, simulates continuous attacking, and renders the answer as an interactive
matrix.

> **Data status:** creature and weapon numbers come from the Valheim Wiki and are not yet
> verified against game files. The *formulas* are from the game code. Plans for
> authoritative data are in [future-ideas.md](future-ideas.md).

## The mechanic (from `assembly_valheim.dll`)

| What | Formula | Code |
|---|---|---|
| Stagger limit | `MaxHealth * m_staggerDamageFactor` (0 = immune) | `Character.GetStaggerTreshold` |
| Max health | `base * level`, level = stars + 1 (`* worldLevel * 2` with world modifiers) | `Character.SetupMaxHealth`, `GetMaxHealthBase` |
| Stagger per hit | `(blunt + slash + pierce + lightning) * attack.m_staggerMultiplier` | `Character.ApplyDamage` |
| ...measured after | attack/combo multiplier, skill roll, resistances, world-level armor, multiplayer scale `1/(1+(n-1)*0.3)` | `Attack.ModifyDamage`, `Character.RPC_Damage` |
| Decay | `-limit / 5` per second (full meter empties in 5 s) | `Character.UpdateStagger` |
| Trigger | meter >= limit, then the meter is clamped to the limit (not reset) | `Character.AddStaggerDamage` |
| Skill roll | `lerp(0.4, 1, skill/100) +- 0.15`, clamped 0..1 | `Skills.GetRandomSkillFactor` |
| Instant stagger | a hit with `m_staggerMultiplier >= 100` (parries) | `Character.RPC_Damage` |

Stars raise the limit (a 2-star needs 3x the stagger of a 0-star), but they don't change your
damage. Because of decay, what matters is **stagger per second against limit/5 per second**,
not just total damage.

## Usage

```bash
uv sync
uv run vstagger fetch     # refresh wiki snapshots -> data/raw/wiki (checked in)
uv run vstagger build     # parse -> data/creatures.json, data/weapons.json
uv run vstagger calc "iron sledge" troll                 # all qualities x stars x attacks
uv run vstagger calc "bronze mace" troll -a secondary -q 4 --skill 40 --roll avg
uv run vstagger report    # -> out/report.html (self-contained, open in a browser)
uv run pytest
```

`calc` / `report` options: `--skill 0-100` (default 100), `--roll min|avg|max` (default `min`,
the guaranteed case), `--players N`, `--world-level N`.

The report has two views. **By creature** shows weapons x quality x attack for one creature at
a chosen star level. **By weapon** shows creatures x stars for one weapon at a chosen quality.
Skill, roll, players and world level are live controls. Each cell shows the swings needed to
stagger; hover a cell for the limit, per-swing stagger, time, and whether the creature dies
first.

## Layout

| Path | What |
|---|---|
| `data/raw/wiki/` | Raw wikitext snapshots + `_manifest.json` (revision ids). Regenerated by `fetch`. |
| `data/attack_profiles.json` | **Hand-curated**: per weapon class, each attack's combo swings (damage multipliers, timings) and stagger multiplier, plus per-weapon overrides. Sourced from the wiki class pages' Properties tables. |
| `data/creatures.json` | Generated: health, stagger factor, damage modifiers, biome, source revision, warnings. |
| `data/weapons.json` | Generated: per-quality damage, resolved attacks, source revision, warnings. |
| `src/valheim_stagger/calc.py` | The canonical calculator (simulation from an empty meter). |
| `src/valheim_stagger/report/` | HTML template + `stagger.js`, a browser port of `calc.py` kept equal by `tests/test_js_parity.py`. |

## Model assumptions

- Attacks repeat their combo nonstop from an empty meter. Swing timings are the wiki's
  measured animation segments, and each hit is placed at the end of its segment.
- "Never" means the meter plateaus below the limit, or is still short after 60 s of nonstop
  attacks.
- "Dies first" counts only physical + lightning damage, so elemental weapons kill even
  sooner than shown.
- Not modeled yet: sneak-attack bonus, weak points, multi-target penalty, status effects,
  parries, the 2x damage taken while already staggered, ranged and magic weapons.
